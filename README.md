# BASSAM JARI Service Hub

نظام شركة خدمات وصيانة ثنائي اللغة باسم **Engineer BASSAM JARI**، مبني على Odoo 19 Community وPostgreSQL 15 باستخدام Docker.

## ما تم بناؤه

- لوحة قيادة تعرض الطلبات النشطة والجاهزة والمسلمة والعملاء والأجهزة والإيرادات.
- دورة صيانة كاملة: جديد، تشخيص، موافقة، إصلاح، جاهز، تسليم أو إلغاء.
- سجل أجهزة لكل عميل مع الرقم التسلسلي وIMEI وسجل الصيانة.
- فروع ومديرو فروع وبيانات اتصال.
- كتالوج خدمات وقطع غيار وأسعار وتكاليف وضمان.
- عرض سعر داخل الطلب مع الكمية والخصم والمدفوع والمتبقي.
- ضمان وتاريخ إنجاز وتسليم.
- Kanban وقائمة ورسوم بيانية وتحليل Pivot.
- Chatter لتتبع تغييرات الحالة والفني والمبالغ.
- بوابة آمنة للعميل مع شريط تقدم وملخص دفع وضمان.
- واجهة إنجليزية وعربية سورية مع دعم RTL.
- عملتان داخل طلبات الصيانة: الليرة السورية `SYP (ل.س)` والدولار `USD ($)`.
- أيقونة تطبيق خاصة تحمل علامة `BJ`.

## التشغيل

من PowerShell داخل هذا المجلد:

```powershell
docker compose up -d
```

ثم افتح:

<http://localhost:8069>

الرابط المباشر للوحة القيادة:

<http://localhost:8069/odoo/action-206>

بيانات إنشاء قاعدة التطوير الأولى:

- Master Password: `admin`
- Database Name: `odoo_learning`
- Email: بريد محلي للتدريب، مثل `admin@example.com`
- Password: كلمة مرور تختارها للدخول إلى Odoo
- Demo data: فعّلها في مشروع التعلم لرؤية بيانات وأمثلة جاهزة

## أوامر مفيدة

```powershell
# عرض حالة الخدمات
docker compose ps

# متابعة سجل Odoo
docker compose logs -f web

# إيقاف البيئة مع الاحتفاظ بالبيانات
docker compose stop

# تشغيلها مجددًا
docker compose start
```

الإضافات التي سنطوّرها توضع داخل `custom_addons`.

## تبديل اللغة

اللغتان `English (US)` و`Arabic (Syria)` مفعّلتان.

1. اضغط صورة المستخدم أعلى اليمين.
2. افتح **Preferences / التفضيلات**.
3. غيّر **Language / اللغة** إلى العربية السورية أو الإنجليزية.
4. احفظ؛ ستتحول العربية تلقائيًا إلى اتجاه RTL.

## تبديل العملة داخل طلب الصيانة

1. افتح **Repair Orders / طلبات الصيانة**.
2. افتح طلبًا أو أنشئ طلبًا جديدًا.
3. من مجموعة **Assignment and Timing / التعيين والمواعيد** اختر حقل **Currency / العملة**.
4. اختر `SYP` لعرض المبالغ بالليرة السورية `ل.س` أو `USD` لعرضها بالدولار `$`.
5. أضف خدمات وقطع غيار مسعّرة بالعملة نفسها.

لوحة القيادة تفصل إيرادات ومستحقات الليرة عن الدولار، ولا تجمع عملتين مختلفتين في رقم مالي واحد. أسعار الصرف لا تُثبت داخل الكود لأنها تتغير؛ عند تركيب المحاسبة تُدار من جدول أسعار العملات القياسي في Odoo.

## بنية الكود

- `custom_addons/repair_center_core`: نماذج الشركة والطلبات والأجهزة والفروع والخدمات والواجهات والترجمة.
- `custom_addons/repair_center_portal`: صفحات تتبع العميل وقواعد الأمان.
- `custom_addons/repair_center_core/i18n/ar_SY.po`: الترجمة العربية المرتبطة بسجلات Odoo.
- `custom_addons/repair_center_portal/scripts/verify_portal.py`: اختبار بوابة العميل والخصوصية.

## تجربة بوابة العميل

افتح نافذة خاصة في المتصفح ثم انتقل إلى:

<http://localhost:8069/my/repairs>

بيانات الحساب التجريبي المحلي:

- Login: `portal`
- Password: `portal`

هذا الحساب مرتبط بالعميل التجريبي `Joel Willis` ويستطيع قراءة طلبه فقط.

يرى العميل في البوابة:

- حالة الإصلاح وشريط تقدم مرئي.
- الجهاز والرقم التسلسلي والفرع والفني.
- موعد الاستلام والإنجاز المتوقع.
- الخدمات والقطع والكميات والأسعار بعملة الطلب.
- إجمالي عرض السعر والمدفوع والمتبقي.
- مدة الضمان وتاريخ انتهائه.

لمنح عميل حقيقي وصولًا للبوابة داخل Odoo:

1. افتح Contacts ثم سجل العميل.
2. استخدم Action ثم Grant Portal Access.
3. تأكد من البريد الإلكتروني وأرسل الدعوة.
4. بعد تعيين كلمة المرور، يدخل العميل إلى `/my` ويرى Repair Orders.

الرابط المباشر للعميل:

<http://localhost:8069/my/repairs>

يرى العميل السجلات المرتبطة بجهة الاتصال الخاصة به فقط؛ قواعد الأمان تمنعه من فتح طلبات أي عميل آخر حتى لو عرف رقم الرابط.

ملاحظة: `localhost` متاح على هذا الجهاز فقط. وصول العملاء من الإنترنت يتطلب نشر Odoo على خادم عام مع Domain وHTTPS وإعداد البريد الصادر.

## المراحل القادمة

1. مخزون حقيقي لقطع الغيار وحركات الإدخال والإخراج.
2. عروض أسعار ومبيعات وفواتير ومدفوعات عبر تطبيقات Odoo القياسية.
3. صلاحيات منفصلة للاستقبال والفني ومدير الفرع والمدير العام.
4. إشعارات بريد وWhatsApp/SMS عند تغير الحالة.
5. تقارير PDF تحمل شعار الشركة وQR لتتبع الطلب.
6. مواعيد، عقود صيانة، موارد بشرية، حضور ورواتب.
